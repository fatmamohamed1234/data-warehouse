# Data Warehouse Project

A SQL and DuckDB project for building a data warehouse and data marts from job posting data.

## Data Marts

- **Flat Mart:** Combines job, company, and skill data.
- **Skills Demand Mart:** Analyzes the demand for different skills over time.
